# Text Motion

Text Motion is a dockable Adobe After Effects ScriptUI panel that applies reusable text-animation setups directly to selected text layers.

## Included Animations

- Line Sweep
- Bounce Up, Right, and Down
- Words Up, Right, and Down
- Characters Up, Right, and Down
- Flicker
- Soft Word Fade

## Features

- Apply an animation to multiple selected text layers at once
- Set a custom animation duration
- Start animations at the current playhead or at the layer's start/in point
- Optionally add an After Effects Glow effect
- Add an editable accent-color control in Effect Controls
- Combine position, opacity, scale, color, range selectors, and temporal easing
- Remove animators and effects generated by Text Motion without deleting the text layer
- Keep generated properties identifiable with the `TM -` prefix

## Installation

Copy `Text Motion.jsx` into the After Effects `Scripts/ScriptUI Panels` directory.

- Windows: `C:\Program Files\Adobe\Adobe After Effects <version>\Support Files\Scripts\ScriptUI Panels\`
- macOS: `/Applications/Adobe After Effects <version>/Scripts/ScriptUI Panels/`

Restart After Effects, then open **Window > Text Motion**.

## Usage

1. Open a composition and select one or more text layers.
2. Set the animation duration.
3. Choose whether the animation starts at the playhead and whether Glow should be added.
4. Click an animation button.
5. Adjust the generated accent color in the layer's Effect Controls if required.
6. Use **Remove Generated Animation** to remove Text Motion properties from the selected layers.

Applying presets repeatedly creates additional generated animators. Remove the existing generated animation first when you want to replace it with a different setup.
